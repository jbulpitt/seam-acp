# Interactive prompts — adoption prompt

Paste this into a consuming software/team repository once:

```text
Persist Seam's agent primer in this project's durable context library so a new
session learns the bridge and seam-MCP without this message:

https://raw.githubusercontent.com/jbulpitt/seam-acp/main/docs/agent-guides/README.md

For human decisions, also retain this canonical guide:
https://raw.githubusercontent.com/jbulpitt/seam-acp/main/docs/agent-guides/interactive-prompts.md

Do not copy their tool schemas or fork their protocol. Add only this project's
local overlay (for example named presets, thread roles, or ingest persistence
paths). A normal decision is a live, single-user frozen choice card; consult the
guide for multi-select, multi-user, cross-thread, or custom behavior. HTTP
submissions are routed from the primer to the separate ingest guide.

After editing, report the context-library path and confirm that a brand-new
session will discover the primer URL.
```

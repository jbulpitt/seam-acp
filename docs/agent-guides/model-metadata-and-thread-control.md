# Model metadata guide moved

This compatibility URL is retained for projects that pinned the earlier
provider-agnostic primer. Its content was almost entirely duplicated by the
Copilot-inclusive guide, which is now the single canonical source:

`https://raw.githubusercontent.com/jbulpitt/seam-acp/main/docs/agent-guides/model-intelligence-and-thread-control.md`

The canonical guide labels `model_value_rankings` as Copilot-only. All other
model metadata and cross-thread session-control guidance applies across agent
backends.

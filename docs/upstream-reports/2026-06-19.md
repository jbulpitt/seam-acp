## Detailed Findings

### Google / Antigravity CLI (agy)

#### New in this period

**agy 1.0.10** (released 2026-06-19 04:29 UTC — today):
- Improved compatibility with ARM64 devices (e.g. Raspberry Pi 4b)
- Added `antigravity_guide` builtin skill — in-context reference for Antigravity 2.0, CLI, IDE, SDK
- Improved commit history navigation: scrolling immediately loads changed files and diffs
- Git: ASCII node graphs (`git log --graph`) for visual parity with hg/jj
- Commit hash matching: resolves short (6-char) to long (64-char) hashes via prefix comparison
- Added alert message type for system errors/warnings (separate from command output)
- Added CLI log file path to `/help` menu
- Upgraded `glamour` to v2.0.1 (cleaner headings/block padding)
- Authentication: auto-launch browser sign-in via `rundll32`
- Fixed permission engine matching — escapes regex metacharacters (`$`, `.`) in saved rules, preventing infinite permission prompt loops
- Fixed environment flag parsing: disablement flags were being ignored
- Fixed bash mode argument escaping; defaults shell resolution to PowerShell

#### seam-acp impact

The permission engine regex fix is relevant: sessions using saved permission rules were potentially stuck in infinite loops if any rule contained regex metacharacters. seam-acp typically uses `--dangerously-skip-permissions` so direct risk is low, but the fix is welcome hygiene.

No gRPC/Connect endpoint changes. No conversation format changes. No CLI flag changes. `agy.ts` needs no code changes.

The new `antigravity_guide` builtin skill ships with 1.0.10 and is available to agy sessions running via seam-acp.

### Anthropic / Claude Code

#### New in this period (since 2026-06-18 sweep)

**claude-code 2.1.183** (latest; we install 2.1.163):
- Destructive git command blocking in auto mode: `git reset --hard`, `git checkout -- .`, `git clean -fd`, `git stash drop`, `git commit --amend` (unless agent authored the commit this session), `terraform/pulumi/cdk destroy` (unless user specified the stack) are now blocked without explicit user request
